# Отчёт по лабораторной работе №4: Ансамбли и полносвязные нейронные сети

## Данные и подготовка

**Датасет:** `german.csv` — данные о кредитоспособности клиентов немецкого банка (1000 записей).
- Целевая переменная: `Creditability` (первый столбец, 0 или 1)
- Признаки: числовые (сумма кредита, срок, возраст) и категориальные (цель кредита, история кредитов, статус счёта)

**Подготовка данных:**
1. **Разделение на train/test:** 80/20 через `train_test_split` с фиксированным `random_state`
2. **Кодирование категориальных признаков:** `pd.get_dummies(drop_first=True)` — создаёт бинарные столбцы для каждой категории, избегая мультиколлинеарности
3. **Масштабирование:** `StandardScaler` (fit на train, transform на test) — критически важно для SVC и нейронных сетей

## Гипотезы и эксперименты

Проведено 4 серии экспериментов с разными random_state (42, 123, 456, 789) для оценки устойчивости моделей к разбиению данных.

**Гипотеза 1:** HistGradientBoosting покажет ROC-AUC ~0.75-0.79 как сильная модель для табличных данных.
- **Результат:** ROC-AUC варьировался от 0.73 до 0.79 в зависимости от split. Лучшие параметры: max_depth=10, learning_rate=0.05, l2_regularization=0.1.

**Гипотеза 2:** SVC с RBF ядром даст хороший результат на маленьком датасете.
- **Результат:** ROC-AUC от 0.76 до 0.79. Лучшие параметры: C=1.0, gamma='scale', kernel='rbf'.

**Гипотеза 3:** RandomForest с большим количеством деревьев (1000+) покажет стабильный результат.
- **Результат:** ROC-AUC от 0.77 до 0.78. Лучшие параметры: n_estimators=1000, max_depth=15.

**Гипотеза 4:** Stacking из трёх моделей (SVC + HGB + RF) даст лучший результат за счёт разнообразия базовых моделей.
- **Результат:** ROC-AUC от 0.78 до **0.8511** (лучший результат при random_state=123).

### Критерий выбора модели

Выбор модели осуществлялся по **ROC-AUC**, так как эта метрика:
- Не зависит от порога классификации
- Оценивает способность модели ранжировать объекты по вероятности
- Наиболее информативна для задач кредитного скоринга

## Выбранная модель

Выбран **Stacking ансамбль** из трёх моделей:
1. **SVC** (C=1.0, gamma='scale', kernel='rbf') — хорошо捕捉ает нелинейные зависимости
2. **HistGradientBoosting** (max_iter=500, max_depth=10, learning_rate=0.05) — мощный градиентный бустинг
3. **RandomForest** (n_estimators=1000, max_depth=15) — стабильный базовый ансамбль

**Финальная модель:** LogisticRegression (C=1.0) обучается на предсказаниях базовых моделей (мета-обучение).

**Почему именно эта модель:**
- Stacking показал лучший ROC-AUC (0.8511) среди всех протестированных подходов
- Разнообразие базовых моделей (SVC + деревья + бустинг) снижает дисперсию предсказаний
- Meta-learner (логистическая регрессия) оптимально комбинирует предсказания

## Выводы и ограничения

**Что улучшило результат:**
- Stacking из разнородных моделей дал +0.05-0.07 к ROC-AUC по сравнению с отдельными моделями
- SVC с RBF ядром хорошо работает на маленьком датасете с нелинейными зависимостями
- HistGradientBoosting с регуляризацией (l2=0.1) предотвращает переобучение

**Что ухудшило результат:**
- Полиномиальные признаки (degree=2) дали переобучение: 210 признаков на 800 примеров снизили ROC-AUC на 0.01-0.02
- Увеличение количества деревьев свыше 1000 не давало прироста качества

**Ограничения:**
- Результаты сильно зависят от конкретного split данных (разброс ROC-AUC от 0.78 до 0.85)
- Низкая accuracy (0.615) при высоком ROC-AUC (0.851) говорит о том, что модель хорошо ранжирует, но порог 0.5 не оптимален
- Для production использования нужно настроить порог классификации под бизнес-метрики
